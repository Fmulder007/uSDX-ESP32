# Эталонные модели DSP (рабочие)

Здесь будут небольшие исполняемые модели отдельных участков DSP, которые можно запускать на ПК без ESP32 и без Arduino Core.

## Текущая модель

- `rx_cic.py` — активный восьмифазный RX CIC из NEW_RX=1.
- `test_rx_cic.py` — проверка расписания функций против прямой каскадной формулы.

## Запуск на Windows

Из каталога `temp\reference`:

    python -m unittest -v

Используются только стандартные модули Python. Ничего устанавливать через pip не требуется.

## Ограничение текущей модели

Это проверка CIC state machine после того, как входные выборки уже разделены на I и Q. Она пока не моделирует:
- переключение ADMUX и конвейер ADC register read;
- интерполяцию I из соседних ADC отсчётов;
- Hilbert, demod, AGC, NR и IIR;
- выходную аудио-интерполяцию.

Модель намеренно ограничена одним блоком: CIC. Результаты тестов подтверждают соответствие восьмифазного расписания прямой двухступенчатой формуле CIC при входах, не вызывающих переполнения 16-bit accumulator.
