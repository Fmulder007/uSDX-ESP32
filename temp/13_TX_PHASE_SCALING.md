# TX — фазовая шкала, MAX_DP и частотная команда

**Источник:** PE1NNZ uSDX, commit bf8acd31b8a2506c4e1d203dfb283feecae947e1.  
**Статус:** формулы и значения выведены из исходника; спектральное влияние и exact AVR arithmetic ещё предстоит измерить.

## 1. Базовая фазовая шкала

В исходнике:

    F_SAMP_TX = 4800
    _UA = 600

_UA означает 600 целочисленных единиц на полный оборот фазы. Для стандартного F_MCU=20 MHz:

    _F_SAMP_TX = 4800
    _F_SAMP_TX / _UA = 8

Поэтому одна единица dp соответствует номинально 8 Hz частотного отклонения:

    df = dp * 8

Фактический Timer2 TX rate при F_CPU=20.007 MHz и integer OCR расчёте равен около 4809,375 Hz. Но код фазовой математики использует _F_SAMP_TX=4800. Не заменять 4800 на фактическое значение таймера без отдельного теста — это уже изменение исходного алгоритма.

## 2. Получение dp

В ssb():

1. Вычисляется phase = arctan3(q,i).
2. Вычисляется dp = phase - prev_phase.
3. prev_phase = phase.
4. Если dp < 0, к dp прибавляется _UA.
5. При включённом QUAD (в выбранной конфигурации он выключен) есть дополнительное преобразование.
6. Выполняется ограничение MAX_DP.
7. Для USB возвращается положительная частотная команда; для остальных mode знак меняется.

То есть dp — не обычное signed delta phase после вычисления производной. Сначала это разность, затем она нормализуется в положительный modulo-интервал 0.._UA.

## 3. MAX_DP зависит от filt

В исходнике:

    #define MAX_DP ((filt == 0) ? _UA : (filt == 3) ? _UA/4 : _UA/2)

При _UA=600, _F_SAMP_TX=4800 и 8 Hz/unit:

| filt | MAX_DP | Максимальная номинальная команда df |
|---:|---:|---:|
| 0 | 600 | 4 800 Hz |
| 1 | 300 | 2 400 Hz |
| 2 | 300 | 2 400 Hz |
| 3 | 150 | 1 200 Hz |

Значения выше описывают предел фазового шага, а не гарантированную полосу передаваемого сигнала. В частности, полный modulo-оборот при filt=0 и физическая частотная интерпретация требуют учитывать дискретную фазовую последовательность и поведение Si5351. Не следует трактовать таблицу как готовую характеристику occupied bandwidth.

Комментарий исходника говорит, что ограничение phase change используется для управления занимаемой SSB полосой.

## 4. MAX_DP — это phase slew limiter с переносом остатка

Код:

    if(dp > MAX_DP) {
        prev_phase = phase - (dp - MAX_DP);
        dp = MAX_DP;
    }

Это важнее, чем просто:

    dp = min(dp, MAX_DP);

Исходник дополнительно меняет prev_phase. Разница dp-MAX_DP не теряется, а переносится в последующие циклы как остаток фазового изменения.

По сути, это ограничитель скорости изменения фазы с сохранением накопленного остатка, а не независимый clipping каждого отсчёта.

При переносе нельзя заменить его на обычный clamp без отдельной спектральной проверки.

## 5. Частотный выход и знаки

Для USB:

    df = dp * (_F_SAMP_TX / _UA)

Для других режимов в этой функции знак противоположный.

В стандартной конфигурации:
- USB: df = +8*dp;
- LSB: df = -8*dp.

CW/AM/FM имеют отдельные передающие функции; не применять к ним эту SSB формулу автоматически.

## 6. Что необходимо проверить

- Поведение dp при переходе phase через 0/600.
- Поведение при малой амплитуде, когда atan2 чувствителен к шуму.
- Действие MAX_DP при filt=0/1/2/3 на спектре.
- Отличие обычного clamp от source algorithm с коррекцией prev_phase.
- Фактическую связь df с частотным обновлением Si5351.
- Расхождение nominal F_SAMP_TX=4800 и actual Timer2 rate≈4809,375 Hz.
- Порядок применения df в конвейере dsp_tx(): вычисление PLL-регистров сейчас и их отправка в следующем цикле.
