## Как читать материалы

В заметках различаются три категории:

- **Факт исходника** — прямо следует из выбранной версии кода; рядом ссылка на исходные строки.
- **Интерпретация** — объяснение взаимодействия функций и алгоритмов.
- **Вариант/предложение** — возможное решение для ESP32, ещё не утверждённое окончательно.

Наличие варианта в документации не означает, что он уже реализован или выбран.
