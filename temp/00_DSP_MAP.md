# Карта DSP uSDX — обзор

**Статус:** первый проход разбора исходника выполнен; требуется детальная проверка численной модели и эталонных сигналов.  
**Источник:** PE1NNZ uSDX, commit bf8acd31b8a2506c4e1d203dfb283feecae947e1.  
**Цель:** перенести алгоритмы звукового тракта, а не монолитную прошивку трансивера.

## 1. Структура системы

- **RX:** I/Q-входы → чередующаяся выборка → CIC-децимация → Hilbert и временное совмещение I/Q → демодуляция/AGC/NR/IIR → аудиосигнал → интерполятор и PWM.
- **TX SSB:** микрофонный ADC → фильтрация и удаление DC → Hilbert I/Q → оценка амплитуды и фазы → разность фаз → частотная команда Si5351; амплитуда отдельно управляет PWM PA.

В исходнике DSP и аппаратура связаны внутри одних функций. При переносе их нужно разделить: DSP выдаёт численные результаты, драйверы аппаратуры применяют их.

## 3. Частоты обработки

| Событие/поток | Частота | Интервал |
|---|---:|---:|
| RX timer event | 62 500 Гц | 16 мкс |
| RX I channel | 31 250 отсчётов/с | 32 мкс |
| RX Q channel | 31 250 отсчётов/с | 32 мкс |
| RX I/Q pair после CIC | 7 812,5 пар/с | 128 мкс |
| TX SSB sample cycle | 4 800 отсчётов/с | 208,33 мкс |
| PWM carrier | 78 125 Гц | 12,8 мкс |
| PWM duty updates через I-ветвь | 31 250 раз/с | 32 мкс |

Значения в таблице — номинальные целевые частоты из исходника. Реальные частоты событий немного отличаются из-за F_CPU=20.007 MHz и целочисленного расчёта OCR; расчёт приведён в [09_ADC_TIMING.md](09_ADC_TIMING.md). Для стандартных настроек получаются примерно 62 521,875 Hz RX, 4 809,375 Hz TX и 78 152,344 Hz PWM carrier. Не смешивать частоту PWM carrier с частотой обновления duty.

## 4. Особенность RX-ввода

Исходный AVR использует один ADC, переключая его между входами I и Q. Выборки не снимаются одновременно. Функция sdr_rx_common_i() дополнительно усредняет предыдущий и текущий I-отсчёты:

    corr_adc = (prev_adc + adc) / 2

Это часть временного согласования I/Q. Нельзя незаметно заменить исходную временную модель одновременными I/Q-выборками без проверки фазовой ошибки и спектрального результата.

## 6. Граница нового DSP-ядра

Разделить будущий проект минимум на четыре уровня:

1. DSP_RX — состояние и математика RX.
2. DSP_TX — состояние и математика TX.
3. Audio I/O adapter — получение выборок и выдача аудио.
4. RF control adapter — применение частотных команд к Si5351 и амплитудных команд к PA.

Внутри DSP не должно быть I2C, GPIO, OLED, Serial, Wi-Fi, динамического выделения памяти или ожиданий аппаратуры.

## 7. Пока не доказано

- Побитовая/численная эквивалентность AVR и ESP32.
- Полный бюджет времени активного RX-пути.
- Источник аналоговых I/Q и микрофонных данных на ESP32.
- Окончательный block size, DMA и распределение задач.
- Эталонные тестовые последовательности и спектральные результаты.
